🎭 Playwright TypeScript Template Base
Este es mi template personalizado de Playwright con TypeScript. Está optimizado para iniciar rápidamente nuevos proyectos de automatización de pruebas sin tener que repetir configuraciones y asegurando la máxima calidad de código.

🚀 Cómo usar este Template para un nuevo proyecto

# 1. Clona el proyecto en una carpeta nueva
git clone <URL_DE_ESTE_REPOSITORIO> mi-nuevo-proyecto
# 2. Entra a la carpeta
cd mi-nuevo-proyecto
# 3. Instala dependencias (incluye ESLint y TypeSccript)
npm install
# 4. Instala los navegadores de Playwright
npx playwright install
